# AnomalyDINO异常检测改进：第11版方法与结果

## 1. 要解决什么问题

工业质检通常有不少合格产品图片，却缺少各种缺陷的样本。AnomalyDINO利用少量正常图片作参考，判断新图片是否异常。

它把图片分成小图块，再用现成视觉模型DINOv2把每块转成数字特征。原方法只检查“测试图中的内容是否像正常内容”。这容易漏掉缺失：例如早餐盒没有香蕉片，剩下的水果和麦片仍然都很正常。

第11版多检查一个问题：**正常参考图中应该出现的内容，在测试图里还能找到吗？**

## 2. 方法怎么做

1. **建立正常参考库。** 每类只使用1张或4张正常图片，保存其图块特征；视觉模型保持冻结，无需重新训练。
2. **保留原来的检查。** 从测试图出发，寻找最相似的正常图块，得到原版异常分数F。
3. **增加反向覆盖检查。** 从正常参考图出发，在测试图里寻找对应内容；越难找到，覆盖分数R越高。沿用原方法的前景规则，减少把参考背景变化当作缺件的情况。

两个方向都取差异最大的1%图块求平均，最终使用固定公式：

```text
最终异常分数 = F + 0.25 × R
```

R在所有选定正常参考图及其旋转视图中联合计算。新增检查只改变整张图的异常分数；原有定位热图保持不变。

## 3. 实验设置与结果

**1-shot / 4-shot**分别指每类用1张 / 4张正常图建库。对照方法使用相同的视觉模型、图片和预处理，每种设置更换3组正常参考图测试。编码器为DINOv2-S/14，图片短边448像素。

测试覆盖MVTec AD的15类、VisA的12类和LOCO的5类。前两者主要检查常见缺陷；LOCO还包含缺件、数量或组合不符合要求的“逻辑异常”。LOCO、VisA使用核验过哈希的公开镜像。

下表是**图像AUROC（%）**：越高表示正常图与异常图区分得越好，50%接近随机，100%为理想区分；它不是分类准确率。括号内为相对原版的变化，单位为百分点。

| 测试内容 | 1-shot：原版 → 第11版 | 4-shot：原版 → 第11版 |
|---|---:|---:|
| MVTec AD：全部异常 | 96.52 → 96.42（-0.10） | 97.55 → 97.50（-0.05） |
| VisA：全部异常 | 85.65 → 85.49（-0.16） | 91.22 → 91.20（-0.02） |
| LOCO：逻辑异常 | 54.31 → 56.75（+2.44） | 62.84 → 65.39（+2.56） |
| LOCO：表面/结构异常 | 70.77 → 70.87（+0.10） | 78.52 → 78.80（+0.29） |

主要收益来自LOCO逻辑异常，提升**2.44 / 2.56个百分点**。MVTec AD、VisA的平均指标略有下降，降幅均小于0.2个百分点；并不是所有异常类型都会改善。

为检查结果是否依赖某几张正常图，另换了60张未进入原参考库的正常图片。逻辑异常仍提升**3.19 / 2.40个百分点**，表面/结构异常变化为−0.02 / +0.12个百分点。这里更换了正常参考图，测试图片仍是同一批。

## 4. 运行开销

方法没有增加新的视觉模型。以A100上线缆图片的实测为例：1-shot单图耗时中位数由61.2毫秒变为61.7毫秒，4-shot由62.9毫秒变为64.3毫秒；显存峰值基本相同，分别约202和526MiB。它增加了少量计算，不能宣传为加速方法。完整耗时和波动范围见[成本表](../results/cost.csv)。

[示例图](../figures/example.png)同时展示了缺失内容被发现和仍然漏检的情况。反向热图画在正常参考图上，不能直接当成测试图的缺陷位置。

## 5. 可以得出什么结论

第11版用一个简单的反向检查补充了原方法，在当前LOCO逻辑异常设置下观察到收益；代价是少量额外计算，以及其他数据集上的轻微平均下降。它仍不能完整理解数量和位置关系，也会受前景筛选和正常参考图选择影响。

**验证边界：这些数据参与过最终方案选择；新增正常参考组检查也复用了测试图。因此结果属于当前基准下的探索和参考稳定性验证，换到完全独立的新场景仍需继续验证。**

方法基于[AnomalyDINO](https://github.com/dammsi/AnomalyDINO)与经典双向最近邻思想，不声称发明新距离。代码、参数、逐图分数和详细结果随本报告提供。
