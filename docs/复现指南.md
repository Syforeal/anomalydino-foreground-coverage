# AnomalyDINO前景一致双向覆盖：复现指南

本目录包含前景一致双向覆盖改进方案及原版AnomalyDINO对照。原始数据、DINOv2权重和大型特征缓存不打包。现有结果来自2026-11-25已完成的实验；此次整理核对分数和指标一致性，没有重新跑完整实验或重新计时。

## 1. 目录与环境

从GitHub克隆或解压Release后，在仓库根目录执行命令。代码、报告和结果直接放在仓库根目录；环境、数据和缓存放在被Git忽略的`work/`中：

```text
anomalydino-foreground-coverage/
  src/、scripts/、configs/、results/、docs/
  work/venv/
  work/dinov2/
  work/dinov2_vits14_pretrain.pth
  work/data/mvtec/、loco/、visa/
  work/features/
```

如果需要复用仓库外已有的`work/`目录，可设置`ANOMALYDINO_WORKSPACE`为包含该目录的路径；默认使用当前仓库根目录。

已测试环境：Python 3.10.21、Torch 2.6.0+cu124；其余版本见requirements.txt。

```bash
P=.
mkdir -p work
python3 -m venv work/venv
work/venv/bin/pip install -r "$P/requirements.txt"
git clone https://github.com/facebookresearch/dinov2.git work/dinov2
git -C work/dinov2 checkout 7764ea0f912e53c92e82eb78a2a1631e92725fc8
curl -L --fail -o work/dinov2_vits14_pretrain.pth https://dl.fbaipublicfiles.com/dinov2/dinov2_vits14/dinov2_vits14_pretrain.pth
```

权重SHA256必须为 `b938bf1bc15cd2ec0feacfe3a1bb553fe8ea9ca46a7e1d8d00217f29aef60cd9`。本包保留了官方AnomalyDINO预处理和前景遮罩代码及其许可，来源见vendor/AnomalyDINO/README.md。

## 2. 运行一个示例

只准备cable类即可测试随包的1-shot库：

```bash
work/venv/bin/python "$P/scripts/download_mvtec_manifest.py" --category cable --root work/data/mvtec --downloads work/downloads
work/venv/bin/python "$P/scripts/coverage_demo.py" predict \
  --bank "$P/deployment/cable_1shot" --data-root work/data/mvtec \
  --dino-repo work/dinov2 --weights work/dinov2_vits14_pretrain.pth \
  --images work/data/mvtec/cable/test/good/000.png work/data/mvtec/cable/test/cable_swap/000.png \
  --device cpu --output work/demo
```

GPU环境可将device改为`cuda:0`；本服务器的GPU任务需在Slurm分配内运行。默认`--head coverage`为本改进方案，`--head baseline`为原版对照。输出连续分数和原版前向patch map，未标定二值通过/失败阈值。

从原始正常图重新建库：

```bash
work/venv/bin/python "$P/scripts/coverage_demo.py" build \
  --bank work/my_bank --config "$P/configs/mvtec.json" --category cable \
  --data-root work/data/mvtec --dino-repo work/dinov2 --weights work/dinov2_vits14_pretrain.pth \
  --images work/data/mvtec/cable/train/good/000.png --device cpu
```

建库不覆盖已存在的库。使用多个正常图时，直接在images后列出这些文件。数据内相对路径参与遮罩的确定性种子，应保持不变。

## 3. 完整数据与实验

MVTec全部类别：去掉下载示例中的`--category cable`。LOCO和VisA使用固定公开镜像；下载、提取后必须通过哈希检查：

```bash
mkdir -p work/downloads
curl -L --fail -o work/downloads/MVTec-LOCO.zip https://huggingface.co/datasets/jiang-cc/MMAD/resolve/c4ed190dcb530f2f673ab293e575ad32054bb3cf/MVTec-LOCO.zip
python3 "$P/scripts/prepare_loco.py" --archive work/downloads/MVTec-LOCO.zip --data work/data/loco --manifest work/loco_manifest.json
curl -L --fail -o work/downloads/VisA.zip https://huggingface.co/datasets/jiang-cc/MMAD/resolve/c4ed190dcb530f2f673ab293e575ad32054bb3cf/VisA.zip
python3 "$P/scripts/prepare_visa.py" --archive work/downloads/VisA.zip --data work/data/visa --manifest work/visa_manifest.json
```

镜像哈希、实际图片数和来源见results/data_manifest_*.json。LOCO镜像含验证图共3651张，与官方页面的3644存在差异；本实验使用其1778张训练、1568张测试的实际清单。QA、caption和验证图不参与方法。

完整评价分两步：先提取特征，再计算分数。以LOCO为例，在GPU分配内运行：

```bash
work/venv/bin/python "$P/scripts/extract_features.py" --config "$P/configs/loco.json" --output work/loco_features
work/venv/bin/python "$P/scripts/evaluate.py" --config "$P/configs/loco.json" --output "$P/results/reproductions/loco"
work/venv/bin/python "$P/scripts/summarize.py" --input "$P/results/reproductions/loco/per_reference.csv" --output "$P/results/reproductions/loco/main_results.csv"
```

也可用Slurm依次提交相同命令，第一步完成后再运行第二步：

```bash
sbatch --partition=a100 --gres=gpu:1 --cpus-per-task=4 --mem=16G --time=00:30:00 --chdir="$PWD" \
  "$P/scripts/run_job.sh" extract "$P/configs/loco.json" work/loco_features
sbatch --partition=a100 --gres=gpu:1 --cpus-per-task=4 --mem=16G --time=00:30:00 --chdir="$PWD" \
  "$P/scripts/run_job.sh" evaluate "$P/configs/loco.json" "$P/results/reproductions/loco"
```

其他数据集替换为mvtec.json、visa.json。loco_reference_audit.json对应固定评价图像、仅更换正常参考图的补充实验。各配置固定β=0.25、top1%，只评价原版和本改进方案。改变权重、预处理或分辨率时应更换缓存命名空间，避免混用缓存。

## 4. 结果文件与检查

- main_results.csv：总体均值、三参考组标准差和差值；AUROC以百分数表示。
- per_category.csv / per_reference.csv：逐类、逐参考组结果。
- predictions/：每张图的标签、原版分数和本改进方案分数。
- cost.csv / runtime_measurements.csv：本改进方案的成本汇总和逐次测量；整理后未重新计时。
- metrics.json / provenance.json：完整统计、参考组无重叠检查、来源哈希和评测设置。

```bash
work/venv/bin/python "$P/scripts/verify_release.py"
# 已准备相同数据和特征缓存时，可额外核对精简代码的实际分数：
work/venv/bin/python "$P/scripts/verify_release.py" --cached-check
```

方法配置通过公开基准上的对比实验确定。复现时使用配置文件中记录的参考组、测试划分和评分参数。新增反向分数用于整图判断，返回的定位map仍来自原版前向距离。
